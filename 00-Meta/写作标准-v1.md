## 1. 工程基线（统一）

**所有文档必须基于以下基线**：

| 维度 | 标准值 | 备注 |
|---|---|---|
| **AOSP 版本** | `android-17.0.0_r1` | AOSP 17 主分支（API 37） |
| **Linux Kernel** | `android17-6.18` | Android 17 GKI 6.18 LTS |
| **硬件 SoC 参考** | Qualcomm SM8550 / MTK 天玑 9200 | 主流量产 SoC |
| **Pixel 设备** | Pixel 7/8 | Tensor G2/G3 + Samsung 4nm |
| **MTK 设备** | 参考 OPPO Find X8 / vivo X100 | MTK 天玑 9300 |
| **Linux 发行版** | Ubuntu 22.04 LTS | 编译/构建主机 |

**frontmatter 必须包含**（缺一项扣分）：

```yaml
---
书卷: 卷 X 标题
章: 第 X 章 标题
节: X.Y 标题
主旨: 一句话讲清本节解决什么稳定性问题
目标读者: 稳定性工程师（级别）+ 角色
前置章节: 第 X 章 / 第 Y 章（按编号）
工程基线: AOSP 17.0.0_r1 + Linux 6.18 GKI + Qualcomm SM8550
源码定位: 
  - path1/to/source1.c
  - path2/to/source2.h
验证方式: dmesg + perfetto + pstore + 抓 log 命令
状态: 🚧 撰写中 / ✅ 完成 / ❌ 废弃
字数: 估算 XXXX（实际由字数统计）
---
```

## 3. 文档结构标准

### 3.1 7 节固定结构（每节都应包含）

```
# X.Y 标题

## 一句话开场
- 用 1-2 句讲清本节解决什么稳定性问题

## 1. 核心子问题
- 列 5-10 个核心子问题
- 每个子问题 1-2 句话

## 2. 详细展开
- 每个子问题 1 节
- 含代码、表格、时序图

## 3. 关键产出
- 输出可执行步骤 / 命令 / SOP
- 含 bash 命令 + 实际路径

## 4. 实战案例
- 真实场景（脱敏）
- 故障 → 定位 → 修复

## 5. Takeaway
- 5-10 条核心要点
- 1 行 1 条

## 6. 前置素材
- 引用已有文章
- 标注前置章节

## 7. 下一步
- 链接下一节
- 链接到其他章节
```

### 3.2 字数与深度

| 章节类型 | 目标字数 | 最低字数 |
|---|---|---|
| 0 篇章首节（7.1/8.1/9.1） | 5000-8000 | 4000 |
| 0 篇章后续节 | 3000-5000 | 2500 |
| 内容章节 | 10000-20000 | 5000 |
| 综合稿（参考素材） | 30000-50000 | 20000 |

### 3.3 内容深度

- **源码引用**：每个核心机制都引用 AOSP 源码路径（如 `system/core/init/init.cpp`）
- **数据基线**：每个性能数字都标注"实测 / 估算 / 推测"
- **版本差异**：AOSP 17 与之前版本的差异（如果有）
- **OEM 案例**：至少 1 个 OEM 案例（Pixel/三星/小米/OPPO/vivo 任一）

## 4. 引用规范

### 4.1 内链格式

- **同章内引用**：`[6.2 启动流程](../02-卷2-系统启动/06-Bootloader%20到%20Kernel/6.2-Bootloader启动流程：PBL-ABL-Kernel.md)`
- **跨章引用**：`[第 12 章 Binder 深度](../03-卷3-核心机制/12-Binder%20IPC%20深度/index.md)`
- **跨卷引用**：`[第 30 章 调查方法论](../04-卷4-诊断方法论与稳定性症状/22-稳定性调查方法论/index.md)`

### 4.2 源码引用格式

```c
// path: system/core/init/init.cpp
// commit: android-17.0.0_r1
// line: 1234
void Init::BootClock() {  // 启动时间戳
    ...
}
```

### 4.3 表格格式

- 第一行：表头
- 第二行：分隔（必须有 `|---|`）
- 第三行起：数据
- 数值列：右对齐（`---:|`）
- 文字列：左对齐（`|---`）

### 4.4 代码块格式

````markdown
```bash
# 启动期 boot log 抓取脚本（adb root 模式）
set -e
OUT=boot_$(date +%Y%m%d_%H%M%S)
mkdir -p $OUT
adb shell su -c 'cat /proc/last_kmsg' > $OUT/last_kmsg.txt
```
````

## 5. 视觉规范

### 5.1 emoji 标记

| emoji | 含义 | 频率 |
|---|---|---|
| 🔴 | 高风险 / 必读 | 每节最多 3 次 |
| 🟡 | 中风险 / 提示 | 每节最多 5 次 |
| 🟢 | 低风险 / 通过 | 每节最多 3 次 |
| 🚧 | 撰写中 | 文件状态 |
| ✅ | 完成 | 文件状态 |
| ❌ | 废弃 | 文件状态 |

### 5.2 关键提示

- 用 `> **🔴 警告**：` 标记必读警告
- 用 `> **🟡 提示**：` 标记可选提示
- 用 `**本节 takeaway**：` 标记总结
- 用 `> 引用：` 标记引用

## 7. 质量等级标准（审计用）

| 等级 | 标准 | 含义 |
|---|---|---|
| **A 优质** | AOSP 17 + 字数 ≥ 10000 + ≥ 10 H2 | 直接发布 |
| **B 良好** | AOSP 14-17 + 字数 ≥ 5000 | 可发布 |
