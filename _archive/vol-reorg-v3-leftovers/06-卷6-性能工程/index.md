## 章节详细

### 第 37 章　性能基线与回归防劣化

> 性能治理的地基——没有基线就没有优化。本章也承载「性能与稳定性的边界与取舍」这一主题。

- 37.1 性能指标体系：启动 / 帧率 / 内存 / 功耗
- 37.2 基线制定：分机型、分场景、分版本
- 37.3 自动化回归与发布门禁
- 37.4 性能压测：Monkey / 场景化 / 长稳测试
- 37.5 性能与稳定性的张力：什么时候该牺牲性能保稳定
- 37.6 趋势分析与劣化归因

**本章小结**：没有基线的性能优化等于盲人摸象——先能测量，再谈优化。

### 第 38 章　应用启动性能

> **应用启动**（点击图标 → 首帧）的优化实践。机制链路见卷 2 第 10 章，**系统开机**性能见卷 2 第 11 章。

- 38.1 启动阶段拆分与耗时归因
- 38.2 Application 优化：初始化编排 / 延迟加载 / Startup 框架
- 38.3 ContentProvider 与四大组件的启动开销
- 38.4 类加载与编译优化：Baseline Profile / dex2oat
- 38.5 资源与布局：首屏渲染的关键路径
- 38.6 启动期稳定性与内存峰值：白屏 / 闪退 / 峰值治理

**本章小结**：应用启动优化的收益集中在「主线程做了什么不该做的事」——去掉比优化更有效。

### 第 39 章　滑动与渲染性能

> 用户日常感知最强的性能。渲染**机制**见卷 3 第 19 章，本章讲**定位与优化**。

- 39.1 帧率指标：FPS / Jank / 卡顿率的定义与陷阱
- 39.2 掉帧归因：主线程 / RenderThread / SurfaceFlinger 三段判定
- 39.3 布局优化：层级 / 过度绘制 / ConstraintLayout / ViewStub
- 39.4 列表与滑动：复用 / 预加载 / 异步化
- 39.5 动画与转场优化
- 39.6 高刷屏适配：90 / 120Hz 的额外挑战

**本章小结**：掉帧归因必须先分清是哪一段超时——主线程、RenderThread、SurfaceFlinger 的修复方向完全不同。

### 第 40 章　低配机适配

> 低端机是性能稳定性的试金石——优化策略与旗舰机不同。

- 40.1 低配机的资源约束特征
- 40.2 内存策略：ZRAM / 分级降配 / 功能裁剪
- 40.3 启动与响应优化的差异化手段
- 40.4 低配机高发问题：OOM / 卡顿 / 被杀
- 40.5 机型分档与能力探测
- 40.6 低配机测试方法与基线

**本章小结**：低配机不是「旗舰机的缩小版」——很多在旗舰机上不成立的瓶颈在这里成为主要矛盾。

### 第 41 章　WebView 与 Hybrid 性能

> 特殊场景——WebView 有独立的进程模型、内存模型与性能方法论。

- 41.1 WebView 架构与进程模型
- 41.2 WebView 内存特征与泄漏模式
- 41.3 JS Bridge 的性能与稳定性风险
- 41.4 加载优化：预热 / 预加载 / 缓存
- 41.5 常见问题：白屏 / 卡顿 / 崩溃
- 41.6 WebView 版本碎片与兼容性

**本章小结**：WebView 内的问题在原生工具里几乎不可见——需要一套独立的观测手段。
