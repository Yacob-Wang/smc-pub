## 这是什么

Android 稳定性是个横跨全栈的领域——一个 ANR 可能源自 Kernel 调度、Native 库、Framework 服务或 App 主线程中的任何一环。但现有资料要么是单层视角的源码解析，要么是应用开发教程，缺一本**以稳定性问题为中心、横跨全栈**的体系化参考。

本仓库按「6 卷 56 章」组织这套知识，从上电启动一路讲到性能治理。完整的章节规划（含尚未撰写的部分）见 **[书籍目录](00-Meta/书籍目录-v1.md)**。

## 本地预览

**推荐（Windows）**：写完/新增文章后，双击根目录 [`同步到Web.cmd`](同步到Web.cmd)  
→ 自动 `prepare_web_docs.py` 同步到 `docs/`，并启动（或复用）`mkdocs serve`，打开浏览器。

等价命令行：

```powershell
powershell -ExecutionPolicy Bypass -File .\sync-web.ps1          # 同步 + 预览
powershell -ExecutionPolicy Bypass -File .\sync-web.ps1 -NoServe # 只同步 docs/
```

首次需安装依赖：

```bash
pip install -r 00-Meta/scripts/requirements-docs.txt
```

手工步骤（与脚本等价）：

```bash
py -3.12 00-Meta/scripts/generate_article_catalog.py   # 刷新目录（可选）
py -3.12 00-Meta/scripts/prepare_web_docs.py           # 生成 docs/
mkdocs serve -a 127.0.0.1:8000
```

预览地址：`http://127.0.0.1:8000/smc-pub/`  
新增或移动文章后，跑一遍 `generate_article_catalog.py` 更新目录；改了书籍目录后，跑 `sync_book_index.py` 重生成各章落地页。  
**GitHub Pages**：push 后 CI 会自动 prepare + build，无需本脚本。
